# IT 168: Structured Problem Solving Using the Computer

## About the Course
The first course in the Computer Science major. It introduces developing algorithms to solve problems with a computer, with an emphasis on structured problem solving and designing solutions before coding. Covers the fundamentals of programming: variables, conditionals, loops, methods, arrays, file I/O, and an introduction to classes, inheritance, and interfaces.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/168/)

**Language:** Java

## What's Here
Each folder is a console program with a `Driver` class that runs it.

| Project | Description |
|---|---|
| `RacingTable` | Calculates Indy 500 driver payouts, laps, and miles covered |
| `PasswordManager` | Creates a password entry with a randomly generated password |
| `NavyAutoaim` | Calculates the angle a ship's gun needs to hit a target at a given range |
| `ChutesAndLadders` | "Eels and Escalators", a dice board game for multiple players |
| `HotelRating` | Generates hotel ratings and finds the best and worst hotels |
| `AirbonReservation` | Menu-driven Airbnb listing and reservation system |
| `StudentGradeBook` | Reads student scores from a file and generates report cards and class stats |
| `BookingSimulation` | Book appointments by period and see which minutes are open |
| `HosbitalRecords` | Hospital patient records using inheritance (regular and COVID patients) |
| `AutoInventory` | Vehicle inventory loaded from a CSV, using an interface and subclasses (Sedan, SUV, Truck) |
| `Garage` | Manage a collection of vehicles: add, edit, search, and save/load |
