# IT 383: Principles of Operating Systems

## About the Course
How operating systems work: processes and threads, scheduling, synchronization, memory management, file systems, I/O device management, and security.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/383/)

**Language:** C

## What's Here
| Project | Description |
|---|---|
| `LearningC` | Getting started with C: strings, reading input, and reading and writing files |
| `Sorting` | A multithreaded sort that splits large lists of numbers across threads |

The `Sorting` project can be built with `make`.
