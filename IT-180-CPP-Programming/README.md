# IT 180: C++ Programming

## About the Course
An introduction to the C++ programming language, with an emphasis on pointers, dynamic memory management, and templates. Prepares students for IT 279, which is taught in C++.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/180/)

**Language:** C++

## What's Here
| Project | Description |
|---|---|
| `IntroToC` | First C++ program: working with arrays and functions (find the highest and lowest values) |
| `StudentInfo` | A `Student` class with header/source files and a makefile |
| `MatricCalculations` | A `Matrix` class with operator overloading for multiplication and equality |

Projects with a `makefile` can be built with `make`.
