# IT 166: Python Programming for Science and Data Analysis

## About the Course
An introduction to programming in Python, focused on writing algorithms for scientific applications and data analysis. The course starts with Python basics and builds up to working with data in libraries like NumPy and pandas, then visualizing it.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/166/)

**Language:** Python (NumPy, pandas, Matplotlib, Jupyter Notebooks)

## What's Here
| Folder | Description |
|---|---|
| `GeneralLearning` | Python basics: data types, data structures, functions, and reading files |
| `PythonLibs` | Getting started with NumPy arrays, pandas DataFrames, and simple graphs |
| `Exercises` | Weekly practice assignments (notebooks and scripts) using real datasets like `students.csv` and `cities.csv` |
