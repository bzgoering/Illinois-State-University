# IT 215: Introduction to Applied Artificial Intelligence

## About the Course
An overview of applied artificial intelligence principles and techniques. Focuses on modern AI technologies and their practical uses, along with the ethical implications and societal impact of AI.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/215/)

**Language:** Python (pygame)

## What's Here
| Project | Description |
|---|---|
| `PythonKnightGame` | A top-down action game where a knight fights waves of goons, brutes, and a boss, with upgrades between levels |

**Run:** `pip install pygame`, then run `python Game.py` from inside the `PythonKnightGame` folder.

**Controls:** `W` `A` `S` `D` to move, `Left Shift` to sprint, `Left Click` to attack.

> The game loads a `medieval_background.png` background that isn't in this folder, so add one before running it.
