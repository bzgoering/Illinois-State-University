# IT 279: Algorithms and Data Structures

## About the Course
A deeper look at data structures and the algorithms that use them: lists, trees, graphs, sorting, and searching. Also covers algorithm correctness, computational complexity, and algorithm design.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/279/)

**Language:** C++

## What's Here
| Project | Description |
|---|---|
| `MemoryWork` | Array list, linked list, and disjoint set implementations with manual memory management |
| `MazeGenerator` | Generates random mazes using a disjoint set (union-find) |
| `SpellCheck` | Builds a dictionary from a word list and checks a file for misspelled words, suggesting corrections |

Projects with a `makefile` can be built with `make`.
