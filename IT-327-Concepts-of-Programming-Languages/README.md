# IT 327: Concepts of Programming Languages

## About the Course
Studies the syntax, semantics, and practical structure of programming languages. Compares procedural, logic-oriented, and object-oriented languages by writing programs in several of them.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/327/)

**Languages:** Python, Rust (the course also covered SML, Prolog, and Go)

## What's Here
| Project | Description |
|---|---|
| `PythonLearning` | Python practice: basic operations, list functions, and inheritance |
| `ChessMoveChecker` | Checks whether chess moves are valid for each piece (Python) |
| `Gradebook` | A gradebook with teacher and student access, written in both Python and Rust |
| `MorseCode` | A group project: a Morse code game built on a binary tree (Rust) |
