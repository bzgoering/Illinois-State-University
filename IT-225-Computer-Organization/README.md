# IT 225: Computer Organization

## About the Course
How a computer is organized and how it works at a low level: how instructions and data are represented inside the machine, and how software and hardware interact. Assignments are written in assembly language for a simple machine.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/225/)

**Language:** MARIE assembly

## What's Here
| Program | Description |
|---|---|
| `MachineCode/Factorial.mas` | Calculates the factorial of an input number, doing multiplication through repeated addition |
| `MachineCode/SortingNumbers.mas` | Reads three numbers and sorts them |

**Run:** open the `.mas` files in the [MARIE simulator](https://marie.js.org/).
