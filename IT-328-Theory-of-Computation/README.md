# IT 328: Introduction to the Theory of Computation

## About the Course
The basic concepts of computing theory: recursive definitions, regular expressions, transition graphs, automata, nondeterminism, grammars, parsing, decidability, and Turing machines.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/328/)

**Language:** Python

## What's Here
| Project | Description |
|---|---|
| `CFGToNPDA` | Reads a context-free grammar from a file and converts it to a nondeterministic pushdown automaton (NPDA) |
| `UnionNPDAWithNFA` | Builds the union of an NPDA and an NFA |

Each project includes `test*.txt` input files.
