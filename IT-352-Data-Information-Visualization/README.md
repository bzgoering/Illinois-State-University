# IT 352: Data and Information Visualization

## About the Course
Methods for visually representing data and information. Covers interactive data visualization, visualization design and evaluation, visual perception and cognition, and interactive web-based visualization.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/352/)

**Language:** Python (pandas, Matplotlib, seaborn, Plotly, Altair)

## What's Here
| Folder | Description |
|---|---|
| `exercises` | Weekly practice assignments, from static charts to interactive visualizations, using datasets like `gapminder.csv` and `co2.csv` |
