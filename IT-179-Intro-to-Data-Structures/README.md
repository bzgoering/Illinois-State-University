# IT 179: Introduction to Data Structures

## About the Course
Intermediate programming that introduces the elementary data structures: linked lists, stacks, queues, and binary trees. Builds on IT 168 by focusing on how data is organized and how to choose the right structure for a problem.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/179/)

**Language:** Java

## What's Here
| Project | Description |
|---|---|
| `BlackjackKnockoff` | Multiplayer card game built around a deck of cards and player hands |
| `PolynomialCalculator` | Adds, subtracts, and multiplies polynomials stored in a custom singly linked list |
| `StoreSimulation` | Simulates a widget factory store over 100 days using queues and deques for inventory and back orders |
