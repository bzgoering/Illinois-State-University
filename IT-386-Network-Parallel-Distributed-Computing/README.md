# IT 386: Introduction to Networking and Parallel and Distributed Computing

## About the Course
An introduction to computer networks and parallel and distributed computing. Covers layered network models, basic switching and routing, TCP/UDP services, network applications, and methods for parallel and distributed computing.

[Course catalog page](https://coursefinder.illinoisstate.edu/it/386/)

**Language:** Java

## What's Here
| Project | Description |
|---|---|
| `Threads` | An introduction to creating and running Java threads |
| `JavaSorting` | Reads numbers from a file and sorts them in parallel |
| `Server` | A multithreaded TCP server that handles multiple clients at once, plus a TCP client |
| `CloudSerice` | A remote calculator using Java RMI: the client sends numbers and the server does the math |
